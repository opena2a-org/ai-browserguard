# Status: beta

**Stage:** beta
**Maintenance horizon:** actively maintained through 2026-12-31. `npm run bump` updates the version in the stage rationale at each release, and the table below records each stage change.
**Maintainer wanted:** no

## Stage rationale

ai-browserguard is a Chrome MV3 extension currently at v0.7.0, published in the Chrome Web Store. Detection has been run against the real Playwright, Puppeteer and Selenium, but the Anthropic Computer Use and OpenAI Operator checks have not been run in Chrome with the extension loaded, the version is still pre-1.0 and the detection rule set continues to evolve with new AI browser-control tools.

## Stage definitions

- **stable**: production-ready, semver honored, breaking changes documented, security patches triaged within 24 hours.
- **beta**: feature-complete or near, breaking changes possible with notice, actively developed.
- **experimental**: early stage, breaking changes expected, use at your own risk.
- **reference-only**: spec or reference implementation, not intended for production use.
