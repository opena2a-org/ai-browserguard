AI Browser Guard — in-page agent fixture

Self-driving page. Open it by hand in your normal Chrome — never through Cowork, Playwright, or any CDP-driven browser (that would tag every agent as external-class and poison the test).

How to run
  1. Press 1 — Trigger detection. It sprays synthetic mousemove/click events (isTrusted:false, bot-like timing) so ABG's behavioral detector fires. Watch for the ABG popup to show a DETECTED card (may take up to ~5 s per its recheck interval).
  2. In the ABG popup, grant Read-Only to this agent (a real click). Note the badge/label it shows (e.g. "Monitor only" vs "Managed").
  3. Press 2 — Fire violations. It waits 600 ms (to clear ABG's 150 ms user-gesture grace window) then attempts one action at a time and logs whether each was blocked. Watch for the block toast.
  4. Copy the log at the bottom and hand it back.
