# Privacy

By default the extension makes zero network requests. All detection, delegation, and session tracking runs locally in the browser, and there is no analytics or telemetry.

Two optional network features are **off by default** and only act after you explicitly enable them:

- **Registry trust lookup** (`api.oa2a.org`): when an agent is detected, look up a trust score for that agent type. Only the detected agent type (for example `playwright`) is sent; never your URLs or page content.
- **Site safety declarations** (the site the agent is on): when an agent is detected on a page, read that site's [`/.well-known/ai-safety.txt`](https://datatracker.ietf.org/doc/draft-fane-ai-safety-txt/) and show what the site claims about its own content. This is the only feature that contacts a server we do not operate. It sends no cookies, no page address, and nothing about you; it follows no redirects; it reads declarations only over HTTPS; and it runs only while an agent is detected, never on pages you browse yourself. A declaration is self-asserted, so it is shown for information and never changes what the extension detects or blocks.

Site safety declarations has a switch in the popup's Settings that turns it off with one click. The registry trust lookup has no switch in the popup: it stays off unless `registryLookupEnabled` in the extension's stored settings (`chrome.storage.local`) is set to `true`, which can be done from the extension's service worker console in Chrome's developer tools, and setting it back to `false` turns it off. Earlier versions also offered an opt-in contribution of detection and behavior summaries to `api.oa2a.org`; it is removed, the extension sends no contribution, and when it updates from an earlier version it clears the contributor token, queued events and consent record that version stored. See [ADR-006](adr/006-opt-in-network-features.md), [ADR-009](adr/009-ai-safety-txt-consumer.md), and the full policy: [opena2a.org/aibrowserguard/privacy](https://opena2a.org/aibrowserguard/privacy).
